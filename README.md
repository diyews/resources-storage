## 下载更新Script
```sh
curl -L -o update.sh https://raw.githubusercontent.com/diyews/resources-storage/refs/heads/linux_scripts/update.sh
```
```sh
chmod +x ./update.sh
```

### 配置文件路径：
```sh
vi /etc/profile.d/custom_env.sh
```
```sh
WECHAT_DEV_NAME="xxx"
WECHAT_PUSH_STATUS="xxx-xxx-xx"
WECHAT_CHECK_UNEXPECTED_DEV=""
```
